# GuideKit VS Code Extension & Codebase Scanner

IDE-to-DOM self-healing product tour authoring and automated workflow scanner for modern web applications.

## Features
- **Device-Code Auth:** Connects seamlessly to your GuideKit developer account using OAuth 2.0 RFC 8628 device flow.
- **AST Route & Element Scanner:** Scans your codebase (Svelte, Next.js, React, Vue, HTML) to map routes, detect auth guards, and discover interactive elements.
- **Workflow & Knowledge Sync:** Syncs scanned workflows and knowledge chunks directly to your GuideKit backend.
- **data-guide-id Codemod:** Automatically injects resilient `data-guide-id` locator attributes into your source files.
- **Headless CLI:** Run scanner and sync operations in CI/CD via `node dist/cli.js`.
